# 🎯 SkillTracker

SkillTracker is a simple and interactive web application that helps users **track their skills, monitor learning progress, set goals, and maintain a daily learning routine**.

It is designed with a clean and user-friendly interface using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- ➕ Add and manage skills
- 📊 Track skill progress with percentage
- 🎯 Set learning goals
- 📈 Visualize learning progress
- 📅 Daily learning tracker
- ✏️ Update skill progress
- 🗑️ Delete skills
- 💾 Store data using browser LocalStorage
- 📱 Responsive and user-friendly interface
- ⚡ Fast and lightweight

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and interactivity
- **LocalStorage** – Store user data in the browser
